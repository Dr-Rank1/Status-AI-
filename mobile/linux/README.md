# Linux desktop overlay

These files supplement the platform scaffold generated by `flutter create --platforms=linux`.

Run the bootstrap script once:

```bash
cd mobile
bash scripts/init-linux-desktop.sh
flutter pub get
flutter run -d linux
```

## Ubuntu dependencies

```bash
sudo apt install \
  clang cmake ninja-build pkg-config \
  libgtk-3-dev libayatana-appindicator3-dev
```

## Features (Phase 15)

| Feature | Implementation |
|---------|----------------|
| Multi-window | `desktop_multi_window` — tray → "Open Messages Window" |
| System tray | `tray_manager` — show/hide main window, quit |
| Desktop notifications | `dbus` → `org.freedesktop.Notifications` for AI DMs |
| Window chrome | `window_manager` — 1280×720 default, hide-to-tray on close |

Close on Linux hides the main window to the tray instead of exiting.
